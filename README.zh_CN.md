# Mouse Synchronization

🌐 [English](README.md) · [Tiếng Việt](README.vi.md) · [বাংলা](README.bn.md) · [हिन्दी](README.hi.md) · [Português (BR)](README.pt_BR.md) · [Русский](README.ru.md) · [Türkçe](README.tr.md) · [اردو](README.ur.md) · **简体中文**

**用一个鼠标同时控制多个窗口。**

Mouse Synchronization 让你选定一个窗口作为“主控窗口”，然后把你在那里的操作——点击、滚动和拖动——同时复制到你想要的任意多个其他窗口。当你打开了同一个应用的多个副本，又厌倦了在每个窗口里重复同样的操作时，它再合适不过了。

由 **Duck Martians** 制作 · [duckmartians.info](https://duckmartians.info)

## 快速上手

1. 打开你想要控制的窗口或应用（例如同一个程序的多个副本）。
2. 打开 **Mouse Synchronization**（运行这个应用）。
3. 按照下面的 5 个步骤操作。

就这么简单——无需设置，无需账号。

---

## 5 步开始使用

1. **找到你的窗口。** 左侧面板 **打开的窗口** 会显示当前所有打开的窗口，你要控制的窗口就在里面。
2. **把它们加入同步列表。** 点击窗口旁边绿色的 **➕**（或选中多个后按 **添加 →**）。它们会移动到右侧面板 **同步列表**。
3. **选择主控窗口。** 在同步列表中，点击你想用来控制的窗口旁边的 **星星 ☆**。它会变成 **金色 ★**——这就是你现在的主窗口。
4. **点击开始。** 点击绿色的 **开始** 按钮（或按 **Ctrl + 1**）。
5. **使用你的主控窗口。** 在主窗口内点击、滚动或按住拖动，列表中的其他所有窗口都会在同一时刻做出完全相同的动作。

要停止，点击 **停止同步**（或 **Ctrl + 2**）。想短暂休息一下而不停止，可以按 **暂停**。

> 你需要先选定一个主窗口，**并且同步列表中至少有 2 个窗口**，“开始”才能生效。

## 屏幕上各个部分的功能

### 左侧面板 — 打开的窗口
实时显示电脑上所有打开的窗口。
- **➕** — 把这个窗口加入同步列表。
- **👁（眼睛）** — 把这个窗口调到最前面，让你能看到它。
- **搜索框** — 输入窗口名称的一部分来筛选列表（例如输入某个程序的名字，隐藏其他所有窗口）。
- **添加全部匹配项** — 一次点击就能添加所有符合搜索条件的窗口。当你要添加 10 个以上的窗口时特别好用。（这个按钮只有在搜索框里输入内容后才有效。）
- **仅当前桌面** — 隐藏位于你其他虚拟桌面上的窗口。

### “打开更多窗口”框
想要一个程序的更多副本？
1. 在 **打开的窗口** 列表中点击一个窗口。
2. 设置你想要的副本数量。
3. 点击 **打开更多**。

应用会找到那个窗口背后的程序，并为你启动额外的副本。
（有些程序只允许自己运行一个副本——那些多出来的副本会直接被关闭。这是程序自身的规则，并不是这里的故障。）

### 中间栏 — 操作
- **添加 → / ← 移除 / 全部移除** — 把窗口移入或移出同步列表。
- **刷新** — 重新扫描打开的窗口（如果某个窗口没有出现在列表里，就用它）。
- **排列** — 自动把你的同步窗口整齐地排成网格。用 **选择显示器** 下面的复选框选择要使用哪些显示器，然后点击“排列”。
- **选择显示器** — 勾选你想把窗口排列到的屏幕。**星星** 标记你的“主”屏幕（这只是应用内部的一个标签——它**不会**改变你的 Windows 设置）。

### 右侧面板 — 同步列表
那些会跟随你主控窗口的窗口。
- **星星 ★** — 选择主控（主）窗口。只能有一个作为主控窗口。
- **👁（眼睛）** — 把那个窗口调到最前面。
- **➖** — 把这个窗口从列表中移除。

### 底部栏 — 控制
- **开始 / 暂停 / 停止** — 运行、暂停或停止同步。
- 每个按钮下方的小框是**键盘快捷键**（见下文）。
- **按窗口比例同步** — 如果你的窗口大小不同或位置不同，就把它**打开**；这样它会按*相对*位置而不是精确坐标来匹配操作。如果你所有的窗口大小相同且排列整齐，就让它保持**关闭**。
- **🏠 主页按钮** — 打开 Duck Martians 网站。
- **🌐 语言按钮** — 更改应用的语言。

## 键盘快捷键

你可以完全不碰按钮就控制一切：

| 操作 | 默认快捷键 |
|--------|------------------|
| 开始  | **Ctrl + 1** |
| 停止   | **Ctrl + 2** |
| 暂停 / 恢复 | **Alt + 1** |

**更改快捷键：** 点击一个快捷键框，输入你想要的按键（例如第一个框输入 `Ctrl`、第二个框输入 `F5`），然后点击别处即可。快捷键框在**同步进行时是锁定的**——如果你想更改，请先停止。

你的快捷键会被**记住**，下次打开应用时依然有效。

## 悬浮状态徽标

同步开始时，屏幕角落会出现一个小徽标：
- **绿色** = 正在同步。
- **琥珀色** = 已暂停。

你可以**点击这个徽标**来暂停或恢复——当其他窗口挡住了应用时特别方便。按下停止后，徽标就会消失。

## 运行本工具的多个副本

你可以多次打开 Mouse Synchronization（每个副本都会有自己的编号，比如“实例 1”“实例 2”）。每个副本都有它**自己**的暂停快捷键（Alt + 它的编号），所以你可以分别暂停它们。

## 值得了解的信息

- **哪些操作会被复制：** 左键点击、右键点击、中键点击、滚动，以及按住拖动（按住左键并移动）——所有在主窗口内完成的操作。
- **窗口名称会有意改变：** 当一个窗口在同步列表中时，应用会在它的标题上加一个像 `[1]`、`[2]` 这样的小编号，方便你区分它们。当你把它们移除或关闭应用时，原来的名称就会恢复。
- **管理员权限：** 应用在没有管理员权限时也能正常运行。但如果你想控制的某个窗口本身是“以管理员身份”运行的，Windows 会阻止一个普通应用去操作它——这种情况下，也请以管理员身份运行 Mouse Synchronization（右键点击应用 → **以管理员身份运行**）。

## 语言与已保存的设置

- 应用支持 **9 种语言**：English、Tiếng Việt、বাংলা、हिन्दी、Português (Brasil)、Русский、Türkçe、اردو 和 简体中文。点击 **🌐 语言按钮** 即可切换——它会立即生效，无需重启。

## 疑难解答

**点击开始没反应／显示警告。**
请确认你已经选定了一个主窗口（金色星星），并且在同步列表中至少添加了 2 个窗口。

**我想要的某个窗口不在列表里。**
点击 **刷新**。如果它在另一个虚拟桌面上，请取消勾选 **仅当前桌面**。

**我点击时其他窗口没有反应。**
你*实际*点击的那个窗口必须是你的主控窗口（带金色星星的那个）。同时请确认同步正在运行（角落里有绿色徽标）。如果你的目标窗口是“以管理员身份”运行的，也请以管理员身份运行本应用。

**窗口没有按我预期的方式排列。**
如果它们大小不同，请打开 **按窗口比例同步**。要把它们整理成网格，请在 **选择显示器** 下勾选显示器，然后点击 **排列**。
