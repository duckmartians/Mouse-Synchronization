## 首次运行

1. **打开你想控制的窗口**--例如同一个程序的多个副本。
2. **运行 Mouse Synchronization。** 左侧面板 **打开的窗口** 会列出当前打开的所有窗口。
3. **把它们加入同步列表。** 点击窗口旁边的绿色 **➕**（或选中多个后按 **添加 →**）。它们会移到右侧面板 **同步列表**。至少需要 **2 个窗口**。
4. **选择主控窗口。** 在同步列表中，点击你要用来操作的窗口旁边的 **星标 ☆**。它会变成 **金色 ★**--这就是你的主窗口。
5. **按下开始**（或 **Ctrl + 1**）。
6. **在主控窗口中操作。** 在里面点击、滚动或按住拖动，列表中的其他所有窗口会在同一时刻做同样的事。

要停止，点击 **停止同步**（或 **Ctrl + 2**）。想短暂休息而不停止，按 **暂停**（**Alt + 1**）。

## 功能

<img width="1100" alt="Mouse Synchronization" src="docs/screenshots/en/main.png" />
<img width="1919" height="1032" alt="Mouse Synchronization" src="https://github.com/user-attachments/assets/c93fee4f-a696-451e-894b-94fe3312fd58" />

- **一个鼠标，多个窗口**--主控窗口内的左键、右键、中键点击、滚动和按住拖动，会同时发送到同步列表中的每个窗口。只同步鼠标，不同步键盘。
- **按窗口比例同步**--当窗口大小或位置不同时，按*相对*位置而不是精确坐标来匹配操作。
- **快速查找和添加窗口**--实时窗口列表，带搜索框、一次添加一整批的 **添加全部匹配**，以及按当前虚拟桌面筛选。
- **网格排列**--把同步窗口整齐排列成网格，放在你选定的显示器上。
- **打开更多窗口**--为某个窗口背后的程序再启动 1-20 个副本。
- **自定义快捷键**--开始、停止和暂停 / 继续，下次打开时仍会保留。
- **悬浮状态徽标**--同步中为绿色，暂停时为琥珀色；点击它即可暂停或继续。
- **同时运行多个工具副本**--每个副本都有自己的编号和自己的暂停快捷键。
- **9 种语言**--用 🌐 按钮即时切换，无需重启。

## 主界面

### 🪟 左侧面板 - 打开的窗口

电脑上所有已打开窗口的实时列表。
- **➕**--把这个窗口加入同步列表。
- **👁**--把这个窗口调到最前面以便查看。
- **搜索框**--输入窗口名称的一部分来筛选列表。
- **添加全部匹配**--一键添加所有与搜索匹配的窗口（需先在搜索框中输入内容才能使用）。要添加 10 个以上窗口时非常方便。
- **仅当前桌面**--隐藏位于其他虚拟桌面上的窗口。

### ➕ 打开更多窗口

想要某个程序的更多副本？在 **打开的窗口** 列表中点选一个窗口，设置 **窗口数量**（1-20），然后点击 **打开更多**。应用会找到该窗口背后的程序并启动额外的副本。有些程序只允许运行一个自身副本--它们会自行关闭多余的副本；这是该程序的规则，不是本工具的错误。

### ↔️ 中间栏 - 操作

- **添加 → / ← 移除 / 全部移除**--把窗口移入或移出同步列表。
- **刷新**--重新扫描打开的窗口（缺少某个窗口时使用）。
- **排列**--把同步窗口整齐排列成网格，放在 **选择显示器** 中勾选的显示器上。
- **选择显示器**--勾选要排列窗口的屏幕。**星标**表示你的"主"屏幕；它只是应用内的标签，**不会**更改 Windows 设置。

### ⭐ 右侧面板 - 同步列表

将跟随主控窗口操作的窗口。
- **星标 ★**--选择主控（主）窗口。只能有一个主控窗口。
- **👁**--把该窗口调到最前面。
- **➖**--把这个窗口从列表中移除。

窗口在同步列表中时，应用会在其标题上加一个小编号，如 `[1]`、`[2]`，方便你区分。当你移除窗口或关闭应用时，原标题会恢复。

### ▶️ 底部栏 - 控制

- **开始 / 暂停 / 停止同步**--开始、暂停或停止同步。每个按钮下方的小框就是它的快捷键。
- **按窗口比例同步**--如果窗口大小不同或位置不同，请**开启**；如果所有窗口大小相同且已对齐，保持**关闭**。
- **🏠**--打开 Duck Martians 网站（[duckmartians.info](https://duckmartians.info)）。
- **🌐**--切换应用语言（English、Tiếng Việt、বাংলা、हिन्दी、Português (Brasil)、Русский、Türkçe、اردو、简体中文）。

## 键盘快捷键

| 操作 | 默认快捷键 |
|---|---|
| 开始 | **Ctrl + 1** |
| 停止 | **Ctrl + 2** |
| 暂停 / 继续 | **Alt + 1** |

**修改快捷键：**点击快捷键框，输入你想要的按键（例如第一个框填 `Ctrl`，第二个框填 `F5`），然后点击别处。**同步进行时快捷键框会被锁定**--需先停止再修改。下次打开应用时，你的快捷键会被保留。

## 悬浮状态徽标

同步开始后，屏幕角落会出现一个小徽标：**绿色** = 同步中，**琥珀色** = 已暂停。**点击徽标**即可暂停或继续--当其他窗口挡住应用时很方便。按下停止后徽标消失。

## 同时运行多个工具副本

你可以多次打开 Mouse Synchronization。每个副本都有自己的编号（"实例 1"、"实例 2"……），显示在标题和暂停按钮上，并有各自默认的暂停快捷键（**Alt + 它的编号**），因此可以分别暂停。

## 故障排除

**按开始没有反应 / 显示警告**--请选择主窗口（金色星标 ★），并向同步列表添加至少 2 个窗口。

**想要的窗口不在列表里**--点击 **刷新**。如果它在另一个虚拟桌面上，取消勾选 **仅当前桌面**。

**点击时其他窗口没有反应**--必须在同步运行时（绿色徽标）于主控窗口（金色星标）内操作。如果目标窗口以"管理员身份"运行，Windows 会阻止普通应用控制它--右键 Mouse Synchronization → **以管理员身份运行**。

**窗口排列不符合预期**--如果大小不同，请开启 **按窗口比例同步**。要排成网格，在 **选择显示器** 中勾选显示器，再点击 **排列**。

**"打开更多"打开的副本马上就关闭了**--该程序只允许运行一个自身副本。

**Windows 显示"Windows 已保护你的电脑"并阻止运行**--点击 **更多信息 → 仍要运行**。本应用没有使用 Microsoft 证书签名--它不是病毒。
