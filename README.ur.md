# Mouse Synchronization

🌐 [English](README.md) · [Tiếng Việt](README.vi.md) · [বাংলা](README.bn.md) · [हिन्दी](README.hi.md) · [Português (BR)](README.pt_BR.md) · [Русский](README.ru.md) · [Türkçe](README.tr.md) · **اردو** · [简体中文](README.zh_CN.md)

**ایک ہی ماؤس سے بیک وقت کئی ونڈوز کو کنٹرول کریں۔**

Mouse Synchronization آپ کو ایک ونڈو کو "لیڈر" کے طور پر منتخب کرنے دیتا ہے اور آپ وہاں جو کچھ بھی کرتے ہیں — کلک، اسکرول، اور ڈریگ — وہ سب اُتنی ہی دوسری ونڈوز میں نقل کر دیتا ہے جتنی آپ چاہیں، اور یہ سب ایک ہی وقت میں ہوتا ہے۔ یہ اُس وقت بہترین ہے جب آپ کے پاس ایک ہی ایپ کی کئی کاپیاں کھلی ہوں اور آپ ہر ایک میں بار بار وہی کام دہراتے دہراتے تھک چکے ہوں۔

بنانے والے **Duck Martians** · [duckmartians.info](https://duckmartians.info)

---

## شروعات کیسے کریں

1. وہ ونڈوز یا ایپس کھولیں جنہیں آپ کنٹرول کرنا چاہتے ہیں (مثال کے طور پر، ایک ہی پروگرام کی کئی کاپیاں)۔
2. **Mouse Synchronization** کھولیں (ایپ چلائیں)۔
3. نیچے دیے گئے 5 مراحل پر عمل کریں۔

بس اتنا ہی — نہ کوئی سیٹ اپ، نہ کوئی اکاؤنٹ۔

---

## 5 مراحل میں استعمال کریں

1. **اپنی ونڈوز ڈھونڈیں۔** بائیں طرف کا پینل، **Open windows**، وہ سب کچھ دکھاتا ہے جو اس وقت کھلا ہوا ہے۔ آپ کی مطلوبہ ونڈوز اسی میں موجود ہیں۔
2. **انہیں sync list میں شامل کریں۔** کسی ونڈو کے ساتھ موجود سبز **➕** پر کلک کریں (یا کئی کو منتخب کر کے **Add →** دبائیں)۔ وہ دائیں طرف کے پینل، **Sync list**، میں چلی جائیں گی۔
3. **لیڈر منتخب کریں۔** Sync list میں، جس ونڈو سے آپ کنٹرول کرنا چاہتے ہیں اُس کے ساتھ موجود **ستارہ ☆** پر کلک کریں۔ یہ **سنہری ★** ہو جائے گا — اب یہی آپ کی مرکزی ونڈو ہے۔
4. **Start دبائیں۔** سبز **Start** بٹن پر کلک کریں (یا **Ctrl + 1** دبائیں)۔
5. **اپنی لیڈر ونڈو استعمال کریں۔** مرکزی ونڈو کے اندر کلک کریں، اسکرول کریں، یا کلک کر کے ڈریگ کریں، اور فہرست میں موجود ہر دوسری ونڈو ٹھیک اُسی لمحے بالکل وہی کام کرے گی۔

روکنے کے لیے، **Stop sync** پر کلک کریں (یا **Ctrl + 2**)۔ مکمل بند کیے بغیر تھوڑی دیر کے لیے وقفہ لینے کے لیے، **Pause** دبائیں۔

> Start کے کام کرنے سے پہلے ضروری ہے کہ آپ نے ایک مرکزی ونڈو منتخب کی ہو **اور sync list میں کم از کم 2 ونڈوز** ہوں۔

## اسکرین کا ہر حصہ کیا کرتا ہے

### بایاں پینل — Open windows
آپ کے کمپیوٹر پر کھلی ہر ونڈو کی ایک زندہ (لائیو) فہرست۔
- **➕** — اس ونڈو کو sync list میں شامل کریں۔
- **👁 (آنکھ)** — اس ونڈو کو سامنے لے آئیں تاکہ آپ اسے دیکھ سکیں۔
- **تلاش کا خانہ** — فہرست کو چھاننے کے لیے کسی ونڈو کے نام کا کچھ حصہ ٹائپ کریں (مثال کے طور پر، کسی پروگرام کا نام ٹائپ کریں تاکہ باقی سب کچھ چھپ جائے)۔
- **Add all matching** — ایک ہی کلک میں ہر وہ ونڈو شامل کر دیتا ہے جو آپ کی تلاش سے میل کھاتی ہو۔ جب آپ کے پاس 10+ ونڈوز شامل کرنی ہوں تو یہ بہت کارآمد ہے۔ (یہ بٹن صرف تب کام کرتا ہے جب آپ تلاش کے خانے میں کچھ ٹائپ کر لیں۔)
- **Only current Desktop** — وہ ونڈوز چھپا دیتا ہے جو آپ کے دوسرے ورچوئل ڈیسک ٹاپس پر موجود ہوں۔

### "Open more windows" کا خانہ
کیا آپ کسی پروگرام کی مزید کاپیاں چاہتے ہیں؟
1. **Open windows** فہرست میں کسی ونڈو پر کلک کریں۔
2. طے کریں کہ آپ کتنی کاپیاں چاہتے ہیں۔
3. **Open more** پر کلک کریں۔

ایپ اُس ونڈو کے پیچھے موجود پروگرام کو ڈھونڈ کر آپ کے لیے اضافی کاپیاں چلا دیتی ہے۔ (کچھ پروگرام اپنی صرف ایک ہی کاپی چلنے کی اجازت دیتے ہیں — وہ اضافی کاپیوں کو محض بند کر دیں گے۔ یہ اُس پروگرام کا اپنا اصول ہے، یہاں کوئی خرابی نہیں۔)

### درمیانی کالم — کارروائیاں
- **Add → / ← Remove / Remove all** — ونڈوز کو sync list میں لائیں اور باہر نکالیں۔
- **Refresh** — کھلی ونڈوز کے لیے دوبارہ اسکین کریں (اگر کوئی ونڈو فہرست میں نظر نہ آ رہی ہو تو اسے استعمال کریں)۔
- **Arrange** — آپ کی sync ونڈوز کو خودکار طور پر ایک صاف ستھرے گرڈ میں ترتیب دے دیتا ہے۔ **Select monitor** کے نیچے موجود چیک باکسز سے منتخب کریں کہ کون سا/کون سے مانیٹر استعمال کرنے ہیں، پھر Arrange پر کلک کریں۔
- **Select monitor** — اُن اسکرینز پر نشان لگائیں جن پر آپ ونڈوز ترتیب دینا چاہتے ہیں۔ **ستارہ** آپ کی "مرکزی" اسکرین کو ظاہر کرتا ہے (یہ صرف ایپ کے اندر ایک لیبل ہے — یہ آپ کی Windows کی سیٹنگز کو **تبدیل نہیں** کرتا)۔

### دایاں پینل — Sync list
وہ ونڈوز جو آپ کی لیڈر کی پیروی کریں گی۔
- **ستارہ ★** — لیڈر (مرکزی) ونڈو منتخب کریں۔ صرف ایک ہی لیڈر ہو سکتی ہے۔
- **👁 (آنکھ)** — اُس ونڈو کو سامنے لے آئیں۔
- **➖** — اس ونڈو کو فہرست سے ہٹا دیں۔

### نچلی پٹی — کنٹرولز
- **Start / Pause / Stop** — sync کو چلائیں، روکیں (وقفہ)، یا بند کریں۔
- ہر بٹن کے نیچے موجود چھوٹے خانے **کی بورڈ شارٹ کٹس** ہیں (نیچے دیکھیں)۔
- **Sync by window ratio** — اگر آپ کی ونڈوز مختلف سائز کی ہوں یا مختلف جگہوں پر ہوں تو اسے **آن** کر دیں؛ پھر یہ کارروائیوں کو درست نقاط (کوآرڈینیٹس) کے بجائے *نسبتی* پوزیشن کے حساب سے میل کرتا ہے۔ اگر آپ کی تمام ونڈوز ایک ہی سائز کی اور قطار میں لگی ہوں تو اسے **آف** ہی رہنے دیں۔
- **🏠 Home بٹن** — Duck Martians کی ویب سائٹ کھولتا ہے۔
- **🌐 Language بٹن** — ایپ کی زبان تبدیل کریں۔

## کی بورڈ شارٹ کٹس

آپ بٹنوں کو چھوئے بغیر ہر چیز کنٹرول کر سکتے ہیں:

| کارروائی | ڈیفالٹ شارٹ کٹ |
|--------|------------------|
| Start  | **Ctrl + 1** |
| Stop   | **Ctrl + 2** |
| Pause / Resume | **Alt + 1** |

**کوئی شارٹ کٹ تبدیل کریں:** کسی شارٹ کٹ کے خانے پر کلک کریں، جو کیز آپ چاہتے ہیں وہ ٹائپ کریں (مثال کے طور پر، پہلے خانے میں `Ctrl` اور دوسرے میں `F5`)، اور کہیں اور کلک کر دیں۔ **sync کے دوران شارٹ کٹ کے خانے مقفل** رہتے ہیں — اگر آپ انہیں تبدیل کرنا چاہتے ہیں تو پہلے sync بند کریں۔

آپ کے شارٹ کٹس اگلی بار ایپ کھولنے پر **یاد رکھے جاتے ہیں**۔

---

## تیرتا ہوا اسٹیٹس بیج

جب sync شروع ہوتا ہے، تو آپ کی اسکرین کے کونے میں ایک چھوٹا سا بیج نمودار ہوتا ہے:
- **سبز** = sync چل رہا ہے۔
- **کہربائی (اَمبر)** = وقفہ (پاز) میں ہے۔

آپ وقفہ کرنے یا دوبارہ چلانے کے لیے **بیج پر کلک** کر سکتے ہیں — یہ اُس وقت کارآمد ہے جب آپ کی دوسری ونڈوز ایپ کو ڈھانپ رہی ہوں۔ Stop دبانے پر بیج غائب ہو جاتا ہے۔

---

## ٹول کی کئی کاپیاں چلانا

آپ Mouse Synchronization کو ایک سے زیادہ بار کھول سکتے ہیں (ہر کاپی کو اپنا نمبر ملتا ہے، جیسے "Instance 1"، "Instance 2")۔ ہر کاپی کا **اپنا** Pause شارٹ کٹ ہوتا ہے (Alt + اُس کا نمبر)، اس لیے آپ انہیں الگ الگ روک سکتے ہیں۔

## جاننا اچھا رہے گا

- **کیا کچھ نقل ہوتا ہے:** بایاں کلک، دایاں کلک، درمیانی کلک، اسکرول، اور کلک کر کے ڈریگ (بایاں بٹن دبائے رکھ کر حرکت دینا) — یہ سب مرکزی ونڈو کے اندر کیا جائے۔
- **ونڈوز کے نام جان بوجھ کر بدلتے ہیں:** جب تک کوئی ونڈو sync list میں ہوتی ہے، ایپ اس کے عنوان میں ایک چھوٹا سا نمبر جیسے `[1]`، `[2]` جوڑ دیتی ہے تاکہ آپ انہیں الگ الگ پہچان سکیں۔ جب آپ انہیں ہٹاتے ہیں یا ایپ بند کرتے ہیں تو اصل نام واپس آ جاتے ہیں۔
- **ایڈمنسٹریٹر کے حقوق:** ایپ ان کے بغیر عام طور پر چلتی ہے۔ لیکن اگر جس ونڈو کو آپ کنٹرول کرنا چاہتے ہیں وہ خود "ایڈمنسٹریٹر کے طور پر" چل رہی ہو، تو Windows کسی عام ایپ کو اسے چھونے سے روک دیتا ہے — ایسی صورت میں، Mouse Synchronization کو بھی ایڈمنسٹریٹر کے طور پر چلائیں (ایپ پر رائٹ کلک کریں → **Run as administrator**)۔

## مسائل کا حل

**Start کچھ نہیں کرتا / ایک وارننگ دکھاتا ہے۔**
یقینی بنائیں کہ آپ نے ایک مرکزی ونڈو منتخب کر لی ہے (سنہری ستارہ) اور sync list میں کم از کم 2 ونڈوز شامل کر دی ہیں۔

**جو ونڈو مجھے چاہیے وہ فہرست میں نہیں ہے۔**
**Refresh** پر کلک کریں۔ اگر یہ کسی دوسرے ورچوئل ڈیسک ٹاپ پر ہے تو **Only current Desktop** کا نشان ہٹا دیں۔

**جب میں کلک کرتا ہوں تو دوسری ونڈوز ردعمل نہیں دیتیں۔**
جس ونڈو پر *دراصل* کلک ہو رہا ہے وہ آپ کی لیڈر ہونی چاہیے (وہی جس پر سنہری ستارہ ہے)۔ نیز یقینی بنائیں کہ sync چل رہا ہے (کونے میں سبز بیج)۔ اگر آپ کی مطلوبہ ونڈو "ایڈمنسٹریٹر کے طور پر" چل رہی ہو، تو اس ایپ کو بھی ایڈمنسٹریٹر کے طور پر چلائیں۔

**ونڈوز اُس طرح قطار میں نہیں لگیں جیسا میں توقع کرتا ہوں۔**
اگر وہ مختلف سائز کی ہیں، تو **Sync by window ratio** کو آن کر دیں۔ انہیں ایک گرڈ میں ترتیب دینے کے لیے، **Select monitor** کے نیچے مانیٹرز پر نشان لگائیں اور **Arrange** پر کلک کریں۔
